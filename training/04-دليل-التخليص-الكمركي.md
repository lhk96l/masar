# 🛃 دليل قسم التخليص الكمركي

> اقرأ أولًا: [الدليل العام](00-دليل-عام-لكل-الموظفين.md)

## 🛃 طابور التخليص
- من القائمة: **«التخليص الكمركي»** → الشحنات في الميناء/قيد التخليص مع رقم البيان والرسوم و**أيام الميناء** (مع تنبيه الأرضيات).

## 📋 البيان الكمركي لشحنة
1. افتح الشحنة → بطاقة **«🛃 البيان الكمركي»** → **«+ إضافة بيان»** أو **«تحديث»**.
2. أدخل: رقم البيان، المركز الكمركي، البند الجمركي (HS)، الوسيط/المخلّص.
3. **الرسوم:** نسبة الرسم، الرسوم الكمركية، الضريبة، رسوم أخرى (الإجمالي يُحسب تلقائيًا).
4. **حالة التخليص:** بانتظار / مُقدّم / قيد المراجعة / مُخلَّص / محتجز.
   - عند اختيار **«مُخلَّص»** تنتقل الشحنة تلقائيًا لمرحلة النقل.
5. **تاريخ وصول الميناء + أيام السماح** → النظام يحسب **الأرضيات** ويُنبّهك قبل تجاوزها (مهم جدًا لتجنّب الغرامات).

## 📜 عمليات الكمارك (CD / LB)
لإدارة المستندات الكمركية (CD) والكفالات (LB) وتجديداتها:
1. من القائمة: **«عمليات الكمارك (CD/LB)»** → **«+ عملية جديدة»**.
2. أدخل: ABR Ref، نوع العملية، العميل، الجهة، الشركة النفطية، العقد.
3. **CD:** الرقم + تاريخ الانتهاء السابق/الجديد. **LB:** الرقم + تاريخ الانتهاء السابق/الجديد.
4. المتابعة: بداية/نهاية العملية، تسليم للحسابات، فاتورة العميل، الحالة.
5. القائمة تُظهر **تنبيهًا ملوّنًا** قرب انتهاء أي CD/LB (أحمر = منتهٍ، أصفر = خلال 30 يومًا).

## 🔔 التنبيهات
- قسم **«التنبيهات»** يجمع لك: انتهاء CD/LB + خطر الأرضيات — **راجعه يوميًا**.

## 📄 المستندات
- ارفع/اربط البيان الكمركي وبقية المستندات في بطاقة **«المستندات»** داخل الشحنة.
