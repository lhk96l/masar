# 🛢️ MASAR — مَسار

### نظام إدارة العمليات والشحنات | شركة عبر الشرق النفطية

نظام داخلي احترافي يدور حول **الإرسالية/الشحنة** كوحدة محورية تمرّ عبر كل أقسام الشركة:
**اللوجستك → التخليص الكمركي → النقل → الحسابات**، مع لوحة معلومات للإدارة وسجل تدقيق كامل.

> تطوير: **م. مهند المظفر** — مدير قسم التكنولوجيا، شركة عبر الشرق النفطية.

---

## ✨ المزايا

- **إدارة الشحنات** بدورة حياة كاملة (مفتوحة → ميناء → تخليص → نقل → تسليم → إغلاق).
- **الموردون** وقاعدة بياناتهم.
- **المستندات** (فاتورة، بوليصة شحن، شهادة منشأ، بيان كمركي...) مخزّنة بأمان في R2.
- **التعليقات والتعاون** على كل شحنة + **مسار زمني** لكل حدث.
- **الإشعارات** عند الإسناد وتغيّر الحالة والتعليقات.
- **المستخدمون والصلاحيات (RBAC)**: مدير، مدير قسم، لوجستك، كمارك، نقل، حسابات، مشاهد.
- **لوحة معلومات** بإحصاءات لحظية + **سجل تدقيق** لكل العمليات.
- **عربي RTL** بالكامل، متجاوب للحاسوب والموبايل، يُفتح برابط واحد.

## 🏗️ المعمارية

| الطبقة | التقنية |
|---|---|
| الواجهة | HTML/CSS/JS (vanilla, ES Modules) — بلا خطوة بناء، تُستضاف على **GitHub Pages** |
| الخادم | **Cloudflare Worker** (ملف واحد `worker/index.js`) |
| قاعدة البيانات | **Cloudflare D1** (SQLite) |
| المستندات | **Cloudflare R2** |
| الأمان | JWT (HMAC-SHA256) + كلمات المرور PBKDF2-SHA256 + RBAC + سجل تدقيق |

## 🚀 النشر (مرّة واحدة)

```bash
# 1) تثبيت الأدوات
npm install

# 2) إنشاء قاعدة D1 ووضع الـ id في wrangler.toml
npm run db:create        # انسخ database_id إلى wrangler.toml

# 3) إنشاء حاوية المستندات R2
npx wrangler r2 bucket create masar-docs

# 4) تطبيق المخطّط والبيانات الأولية
npm run db:schema
npm run db:seed

# 5) ضبط الأسرار
npx wrangler secret put JWT_SECRET      # سرّ عشوائي طويل
npx wrangler secret put SETUP_TOKEN     # توكن لمرة واحدة لإنشاء أول مدير

# 6) نشر الخادم
npm run deploy

# 7) ضع رابط الـ Worker في docs/js/config.js (API_BASE)
# 8) فعّل GitHub Pages من فرع main / مجلد /docs
```

### إنشاء أول مدير
افتح التطبيق → «إعداد النظام لأول مرة» → أدخل `SETUP_TOKEN` وبيانات المدير. يعمل مرة واحدة فقط.

## 🔐 الأدوار والصلاحيات

| الدور | الصلاحية |
|---|---|
| `admin` | كل شيء |
| `manager` | كل شيء + إدارة المستخدمين |
| `logistics` | إنشاء/تعديل الشحنات والموردين والمستندات |
| `customs` | تحديث البيانات الكمركية والمستندات |
| `transport` | تحديث أوامر النقل |
| `accounting` | السجلات المالية |
| `viewer` | قراءة فقط |
